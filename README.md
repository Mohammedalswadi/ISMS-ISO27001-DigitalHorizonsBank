# Information Security Management System (ISMS) Implementation
## ISO/IEC 27001:2022 — Case Study: Digital Horizons Bank (بنك الآفاق الرقمية)

## 📋 Overview

This repository contains a complete **Information Security Management System (ISMS)** documentation package, designed and implemented according to **ISO/IEC 27001:2022**, based on a realistic case study of a fictional Saudi bank, *Digital Horizons Bank* (بنك الآفاق الرقمية).

The project was developed as a graduation/course project for the **Information Security Management Systems** course, covering the full lifecycle of ISMS design: from initial gap analysis to certification readiness assessment.

## 🎯 Project Objectives

- Conduct a comprehensive gap analysis against ISO/IEC 27001:2022 requirements (clauses 4–10 and all 93 Annex A controls).
- Build an asset-based information asset inventory and risk register.
- Design the foundational ISMS documents: context & scope, information security policy, objectives, risk methodology, risk appetite, and Statement of Applicability (SoA).
- Develop supporting policies and procedures: Acceptable Use Policy, Incident Response, Business Continuity & Disaster Recovery, Secure Operating Procedures, and Secure Configuration Baseline.
- Establish monitoring, internal audit, and continual improvement mechanisms.
- Assess the organization's readiness for external ISO/IEC 27001:2022 certification audit.

## 🧩 Methodology

The project follows the **Plan–Do–Check–Act (PDCA)** cycle mandated by ISO/IEC 27001:2022:

1. **Plan** – Context analysis, gap assessment, asset inventory, risk assessment.
2. **Do** – Policy and procedure development, control implementation per the SoA.
3. **Check** – Monitoring & measurement, internal audit.
4. **Act** – Corrective actions, document updates, certification readiness.
